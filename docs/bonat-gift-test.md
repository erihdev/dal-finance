# اختبار منفّذ هدية بونات (بلا إرسال)

**الحالة:** المنفّذ في `tools/dal_browser/mk_exec.js` (`ADAPTERS.bonat`). لم يُجرَّب حياً. لا يُرسل شيئاً ما لم يُضبط `MK_SEND_BONAT=1` **و** `MK_BONAT_DRY=0`.

## متغيّرات التشغيل للتجربة (Railway)
- `MK_BONAT_TEST_PHONE=0596661678` — حارس: لا يُنفَّذ إلا لهذا الرقم.
- `MK_BONAT_DRY` غير مضبوط (أو غير `0`) — يملأ نموذج بونات ولا يضغط «إرسال هدية».
- `MK_SEND_BONAT=1` — مطلوب كي يتجاوز البوابة إلى المنفّذ (الوضع التجريبي يمنع الإرسال الفعلي).

## مقترح الاختبار (يُضاف إلى `live/mk_props` ثم يعتمده المالك من تبويب الاعتمادات)
```json
{
  "id": "MKTEST-BONAT-1",
  "key": "bonat-gift-test",
  "kind": "birthday",
  "platform": "bonat",
  "platformName": "بونات",
  "action": "gift",
  "title": "اختبار: هدية عيد ميلاد لرقم الاختبار",
  "audience": { "phone": "0596661678", "label": "رقم الاختبار" },
  "copy": { "title_ar": "عيد ميلاد سعيد من محمصة دالـ 🧡✨" },
  "schedule": "now",
  "why": ["اختبار المنفّذ على عميل واحد قبل أي تفعيل"]
}
```

## النتيجة المتوقعة في `live/mk_runs`
- `dry_run`: النموذج امتلأ ولم يُضغط الإرسال → التجربة نجحت.
- `failed`/`needs_template`: رسالة السبب (مثلاً العميل غير موجود في بونات، أو لا قالب بهذا العنوان).

## غير مدعوم عمداً
إنشاء قوالب جديدة، أنواع الهدية غير النسبة المئوية. الجدولة مدعومة بصيغة `YYYY-MM-DD HH:mm` (خطوة 30 دقيقة) لكن تسلسلها لم يُجرَّب حياً.
